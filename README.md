# Little Story Garden · 家庭互动绘本阅读器 V2

一本书就是一集。内置《Hide and Seek》的六张真实页面和两套完整音频，也可以导入自己的 PDF 或截图，制作新的课程。

## 安卓平板网页版

打开 https://tonylin231011.github.io/little-story-garden/ 即可在线阅读，不需要家里的电脑开机。首次使用请在有网时打开，等页面及内置六页图片、两套语音下载完成；随后可在 Chrome 菜单中点「添加到主屏幕」，外出无网时也能从图标打开。网站由 [.github/workflows/publish-site.yml](.github/workflows/publish-site.yml) 随 `main` 分支自动发布。

网站是公开地址，内置课程图片和音频也可被访问。学习进度、家长编辑的课程及平板导入的图片 / 音频仅保存在当前浏览器，不自动同步到电脑；清理网站数据会删除这些内容。网站支持手动导入 PDF / 截图制作新集，但视觉 AI 自动生成需要本机 Node 服务，在线静态站点不提供这个功能。

断网前可用飞行模式验证：已安装的网站应能打开内置绘本、图片和语音。若首次下载未完成，回到联网状态重新打开并稍等；安卓系统的浏览器数据清理可能移除离线资源。

## 本机启动

需要 Node.js 20 或更新版本，以及支持现代 JavaScript 的 Chrome / Edge 浏览器。交付包已包含 PDF 阅读组件和音频，普通使用无需安装项目依赖。

- Windows：首次双击「启动阅读器.cmd」，会为当前 Windows 用户安装常驻任务并打开页面。此后登录 Windows 会自动启动，直接打开固定链接即可；重复双击会复用现有服务。
- 固定地址：http://127.0.0.1:4173/ 。同一台电脑的 Codex、Chrome、Edge 均可打开，版本查询参数不影响地址。
- 其它系统 / 手动开发可在项目目录运行 `npm start`；这不提供 Windows 常驻功能，勿与已运行的常驻服务同时占用端口。
- 服务只监听本机。命令行运行时按 Ctrl+C 停止；不要直接双击 index.html。
- 程序恢复就绪后刷新原标签页即可；不用清理浏览器数据。

## Windows 常驻运行

后台分两层恢复：守护进程每 2.5 秒检查本机阅读器，进程退出后按 1–30 秒退避重新启动，持续无响应时重新启动自己管理的进程；Windows 在登录时启动守护进程，并每分钟检查是否需要再次启动它。已有实例运行时跳过重复启动；插电和使用电池都允许运行，没有默认的数天运行时限。仅在当前用户登录期间运行，不保存 Windows 密码。

电脑关机、未登录或休眠时无法提供本机网页；登录 / 唤醒后等待服务就绪即可。浏览器仅打开链接不会自己执行本地程序，链接长期可用依靠已安装的常驻任务。无需保持 Codex、调试终端或浏览器窗口打开。

- **查看运行状态.cmd**：显示当前状态及诊断位置。
- **修复并启动.cmd**：重启本项目的常驻组件并打开页面，不删除素材或浏览器数据。
- **停用常驻服务.cmd**：卸载本用户的自动任务、停止本项目进程，保留图片、音频和学习记录。之后如再双击启动器，会重新启用常驻运行。
- 诊断保存在 `.runtime/reader-4173/`，包括状态及最多约 4 MB 的滚动日志；不记录页面文本、录音或 API 请求内容。日志不收入下载包。

Windows 任务名以 `LittleStoryGarden-` 开头，任务位置与源码位置绑定。保持安装目录不变；需要移动时先在旧目录停用，再在新目录启动安装。同一 Windows 用户只安装一份，避免不同文件夹争抢 4173 端口。浏览器中的书架和进度按访问地址及浏览器分别保存；外部浏览器可以打开服务，但不会自动获得 Codex 内浏览器中导入的新书。

## 从 PDF / 截图制作新的一集

1. 点右上角「书架」→「制作新的一集」，填写名称。
2. 选择一个 PDF，或一组 PNG / JPG / WebP 截图。每集 1–40 页，文件合计不超过 80 MB。
3. 检查缩略图，用箭头调整顺序、移除不需要的页；PDF 可提取的文字会填入正文草稿。
4. 点「生成课程草稿」，进入家长区。此时只是本机整理素材，没有调用云端 AI。
5. 补充或修改正文、题目和热点。没有正文的页面要明确勾选「这一页没有正文」。
6. 每道题确认正确后勾选「已审核」，再点「审核后发布这一集」。未审核或未启用的题目不会出现在孩子的课程中。

截图和扫描 PDF 不会自动在本机识字。可以手动填写，也可以在选好视觉 AI 服务后使用自动生成。PDF 当前不支持密码保护文件。导入图片缩放至最长边 1600 像素保存，方便本机播放和后续识图；请保留原始素材。

每一集独立保存页面、正文、热点、问题、导入音频、阅读进度和练习记录。草稿可下次继续编辑；已发布课程修改后保存草稿，需要再次发布。切换书籍时清除临时跟读录音，避免不同书的相同页码混用。

## 可切换的视觉 AI 接口

当前没有指定服务商，也没有配置或调用真实视觉 AI 服务。已实现 OpenAI-compatible **Chat Completions** 协议，可填写支持图片输入的兼容服务地址、模型与 API Key。仅有“OpenAI 兼容”文字并不保证所有模型均兼容；需支持 `messages` 中的 `image_url` 数据图片、`max_tokens` 参数以及 JSON 文本回答。其它协议可在 `server/ai.mjs` 中增加适配。

选好服务后：

1. 把项目中的 `.env.example` 复制为 `.env.local`。
2. 在本机文件里填写以下四项，密钥无需粘贴到聊天或网页源码：

```dotenv
STORY_AI_PROVIDER_NAME=服务显示名称
STORY_AI_BASE_URL=https://provider.example/v1
STORY_AI_MODEL=支持视觉输入的模型名
STORY_AI_API_KEY=该服务的密钥
```

3. 地址写到 API 版本目录，程序会追加 `/chat/completions`；仅支持 HTTPS，不自动跟随重定向。
4. 重启本机服务，在课程家长区点「AI 生成正文、问题与热点」。
5. 页面先显示服务、地址、模型、书名和本次全部页数。勾选确认后才发送。

发送内容：该集的页面图片、提取 / 编辑的英文正文、书名和教学要求。不会发送孩子录音、学习记录或已有的音频文件。密钥由本机服务读取，不返回给浏览器。

每页一次请求，按顺序处理，每次最多输出 4096 tokens。实际费用由所选服务决定。失败不自动重试；整集成功后才替换草稿，失败保留原内容。可以取消后续处理，已经发生的服务调用可能仍计费。

AI 结果包括正文、热点、短问题和中文带读建议，题目全部标记为待审核。家长需核对识字、答案及热点位置。生成课程内容与生成语音是两个独立步骤；本版没有自动为新书调用 TTS。

## 孩子的阅读流程

- **Read**：看图、Listen 朗读、Slow 慢速、Stop 停止。没有音频时可由家长带读，再点 We read together。
- **Play**：一次一道题；可选择 Word Questions / Story Questions。
- **Point & Find**：直接点击画面，两次未找到后提供热点提示和一起完成入口。
- **选择题、跟读、亲子讨论**：短问题，选择题 2–3 个选项；讨论可用中文回答。
- **一句一练**：示范、最长 15 秒录音、回听。录音仅存在当前标签页内存，刷新或换书清除，不上传、不评分。
- **复习与完成页**：页数跟随每本书；提示过的题优先再练，每轮最多 5 题，独立完成后按 1、3、7 天复习。同一到期前重复答题不会提前跳级。

家长记录区分独立完成、重试 / 一起完成、跟读 / 讨论参与，不把点击记录当成语言水平或发音成绩。Read again 重新开始本集阅读进度，保留编辑内容、导入音频和学习历史。

## 声音

《Hide and Seek》已内置智小柔（502001）与 WeWinny（501009）两套音频，每套覆盖 100 段去重文本。另有三份短句试听，共 203 个音频文件，均有本机 PCM WAV 兼容版本。它们是腾讯云 AI 合成声音，不是出版社原版录音。播放现有文件不调用云端，也不消耗生成额度。

新书正文和新问题需要配对应的录音。家长区可以给整页、题目、选项、反馈或热点词导入音频；支持浏览器可解码的 MP3 / WAV / M4A / OGG，单个最大 30 MB。录音保存到本机浏览器，不上传。

播放优先级：本集整页导入音频 > 本集单句导入音频 > 内置包中完全匹配的文本。不同书的整页录音不会串用。损坏文件有匹配的内置音频时尝试后备；无可用音频时明确提示，不调用机械浏览器 TTS，也不会播放其它文字的录音。

听不到时先点「开启声音」和 Listen，再检查标签页静音、Windows 音量与输出设备。家长区「声音测试与排查」可导出诊断。浏览器报告播放结束不能证明扬声器物理出声。

### 可选：后续重新生成腾讯云语音

普通播放不需要 SDK 或密钥。原有命令行工具保留在 `scripts/tencent_tts.py`：导出 Lesson JSON 后用 `--lesson` 指定课程；先运行 `--dry-run` 查看文本数量。工具仅读取进程环境中的 `TENCENT_SECRET_ID`、`TENCENT_SECRET_KEY`，用 `--max-characters` 限制本次发送量，已成功的相同文本命中本地缓存，失败不自动重试。

该工具需官方 `tencentcloud-sdk-python-tts` SDK。生成后用 `scripts/prepare_audio.py` 转 PCM WAV，该转换步骤需本机 FFmpeg。新集不会因点击播放而自动调用此工具。

## 家长编辑与保存

家长区支持修改正文、问题、中文提示、选项、正确答案、启用 / 审核状态。选择热点后在原图拖出矩形，也可输入相对于整图的 0–1 坐标。无效坐标或答案会阻止发布。

书架存在当前浏览器的 IndexedDB，进度和编辑副本保存在本机浏览器存储。不同浏览器、设备或访问地址不会自动同步。清理站点数据会删除这些内容。

可导出 Lesson JSON、进度和学习记录。**Lesson JSON 不包含图片、导入音频或孩子的临时录音，不能作为完整的跨设备备份。** 新课程的 JSON 中引用本机图片，在同一浏览器中可重新导入审核；换设备需保留原始 PDF / 截图和音频，重新导入素材。当前没有全书素材打包备份功能。

## 开发与验证

- `npm run check`：JavaScript 语法检查。
- `npm test`：19 个核心、PCM、复习、课程与 AI 接口测试。
- `npm run build`：生成静态 `dist`。静态托管支持本机书架与阅读，**云端生成仍需运行 Node 服务的 `/api/ai/*` 接口**。
- `python tests/e2e.py`：12 项原课程阅读、互动、编辑和手机验证。
- `python tests/audio_e2e.py`：18 项音频、麦克风异常、自动播放限制、后备播放和 HTTP 范围请求验证。
- `python tests/library_e2e.py`：8 项截图 / PDF、新集发布、独立进度、AI 确认 / 审核 / 失败保护与手机书架验证。
- `python tests/library_edges_e2e.py`：3 项跨书录音隔离、恢复导入声音和 40 页手机课程验证。
- `powershell -File tests/service-recovery.ps1`：验证实际安装的 Windows 常驻任务及两层自动恢复，会短暂结束本项目进程。
- `python tests/edge-smoke.py`：使用本机 Edge 验证固定链接、真实图片、书架和新集入口。
- 常驻方案与验证边界见 [本机常驻说明](./docs/resident-service.md)。

浏览器测试需要 Python Playwright 与 Chromium，运行前先启动本机服务。测试使用独立浏览器环境，不修改日常书架；录音测试使用虚拟麦克风和测试纯音。AI 使用模拟响应和本机 HTTP 边界测试，没有向真实云端发送绘本。真实服务联调需等待服务商和模型确定。

普通自动化测试允许测试脚本求值；音频另有正式 CSP 下的播放验证。PDF 拆页及手机书架截图经过人工视觉检查。测试在独立 Chromium 完成，未直接验证 Codex 应用内浏览器的实际扬声器出声。

## 文件说明

- `public/lesson.json`、`public/images/`：《Hide and Seek》示例课程及六张真实原图，未用 AI 重绘。
- `public/audio/`：可替换音频包和映射。
- `public/vendor/pdfjs/`：本机 PDF 组件及 Apache-2.0 许可证。
- `src/library.js`、`src/library-ui.js`：多集书架和导入向导。
- `src/importer.js`：本机拆页、文字提取、截图整理。
- `src/generation.js`、`server/ai.mjs`：可切换视觉 AI 适配和生成校验。
- `src/app.js`、`src/core.js`：阅读、互动、编辑和课程规格校验。
- `src/audio.js`、`src/wav.js`、`src/learning.js`：本机音频、PCM、录音和复习。
- `server.mjs`：本机 HTTP 服务、健康检查，读取 `.env.local`，不需要运行时第三方依赖。
- `server/reader-supervisor.mjs`、`scripts/*ReaderService.ps1`：Windows 常驻、异常恢复、诊断和停用。
- `docs/qiqixue-comparison.md`：既有奇奇学公开资料对标和能力边界。

PDF 组件已随包提供。开发时只有更新组件才需 `npm install` 和 `npm run vendor:pdf`；相关源码与文档见 https://github.com/mozilla/pdf.js 。

《Hide and Seek》原对话 JSON 在最后一页中段截断，现有最后一页及复习按当时的产品规格补齐；六图按真实内容排序，窗边女孩所在页的问题和热点已校准。其它书的内容由家庭导入、编辑和审核。
