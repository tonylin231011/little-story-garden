# 奇奇学对标与本版实现
调研日期：2026-09-25。范围：公开的开发者介绍与版本记录，未进入付费课程逐课体验。

## 结论
希望达到可替代的使用体验，重点是让孩子完成“理解故事、愿意开口、作出回应、再次见面”的过程。只增加题目数量或更换声音，不能补齐这些环节。

奇奇学开发者在 App Store 介绍了牛津树分级内容、双语精讲，以及精讲、跟读、问答、游戏、复习的五环节设计，并提供配套听读。它还有远大于单本原型的课程规模。这些是开发者描述，不等于本次实测结论。
来源：[奇奇学 App Store 开发者页面](https://apps.apple.com/cn/app/id1548233137)。
[小米应用商店开发者页面](https://app.mi.com/details?id=com.ximalaya.qiqi.android&type=pad)也列出了同类学习环节。

## 《Hide and Seek》对应实现

本版新增了跟读回听、带读提示、复习队列和家长学习记录。原有阅读、词汇题、故事题、指图、选择题、亲子讨论、审核和完成页继续保留。

## 给零基础孩子的使用方式
1. 从一页开始，先看图、听一句，家长用动作或中文帮孩子理解。
2. 孩子愿意时模仿一个词或一句话；录音回听是可选项。
3. 让孩子自己找一次，等几秒再帮助。不要反复催答。
4. 完成后去生活里玩一次捉迷藏；下次回来再练需要提示的题。

这是本项目的设计建议，不是对奇奇学付费课程的复刻，也不承诺特定学习效果。录音不做真假“AI 得分”，点击完成也不记为语言掌握。

## 后续达到更高替代程度的验收目标
- 家长可以直接使用的逐页双语讲解和互动台词，而不仅是提示文字。
- 在实际使用设备上验证声音启动、后台恢复、连续阅读和麦克风权限。
- 观察孩子能否独立理解界面、完成一道找图题、愿意回听一句话，据此减少按钮和调整节奏。
- 扩展绘本与跨书词汇复习；目前范围仍是用户提供的这一本书。

因此，V1.2 是单本阅读与练习流程的增强版。目前不能称为整个奇奇学课程体系的全面平替。
